title: Answer blocks
description: Your answers as small checked sentences — the same facts in every round, any question answered by a chain.
---

The pack keeps answers not as texts but as **blocks**: small checked sentences in English and your native language. Any answer to any question for any company is a chain of them, so your facts stay the same in every interview.

| Type | What it is |
| --- | --- |
| `S` | the whole story in 20–40 seconds; answers the question on its own |
| `O` | the first line — the answer straight away |
| `C` | context: where, who, scale |
| `A` | what I did — an I-sentence |
| `R` | the result with a number |
| `D` | how the number was measured |
| `L` | the lesson, the rule since |
| `P` | a position, a belief |
| `G` | an honest gap in one sentence |
| `Q` | an answer to a frequent follow-up |

Two rules: every block reads without its neighbours (it names the project, never opens with «Then» or «That»), and every story has a whole-story block for a short answer.

**Recipes** map each of the 134 bank questions to a first line and two chains (short for a recruiter, long for a hiring manager). The bank has 26 core questions for any role, role packs, and 13 story archetypes that usually take 10–12 stories.

A made-up example cut into blocks: [examples/example-story.md](https://github.com/butyavk/job-search-kit/blob/main/examples/example-story.md).

`check_pack.py` checks the format, links, the English register and coverage; once a month a separate agent checks every block against every source of facts.
