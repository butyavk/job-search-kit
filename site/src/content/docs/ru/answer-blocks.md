---
title: Кубики ответов
description: Ответы как маленькие проверенные фразы — одни и те же факты в каждом раунде, любой вопрос цепочкой.
---

Пакет хранит ответы не текстами, а **кубиками**: маленькими проверенными фразами на английском и на вашем родном языке, если он не английский. Любой ответ на любой вопрос для любой компании — цепочка кубиков, поэтому факты на всех интервью одни и те же.

| Тип | Что это |
| --- | --- |
| `S` | вся история за 20–40 секунд; сама отвечает на вопрос |
| `O` | первая фраза — сразу ответ |
| `C` | контекст: где, кто, масштаб |
| `A` | что сделал я — I-фраза |
| `R` | результат с числом |
| `D` | как мерили число |
| `L` | вывод, правило после |
| `P` | позиция, убеждение |
| `G` | честный пробел одной фразой |
| `Q` | ответ на частое уточнение |

Два правила: каждый кубик читается без соседей (в нём назван проект, нет «Потом» или «Это» в начале), и у каждой истории есть кубик-целое для короткого ответа.

**Рецепты** связывают каждый из 134 вопросов банка с первой фразой и двумя цепочками (короткая — для рекрутёра, длинная — для нанимающего менеджера). В банке 26 вопросов ядра для любой роли, ролевые пакеты и 13 архетипов историй, которые обычно закрывают 10–12 историй.

Выдуманный пример, нарезанный на кубики: [examples/example-story.md](https://github.com/butyavk/job-search-kit/blob/main/examples/example-story.md).

`check_pack.py` проверяет формат, ссылки, регистр английского и покрытие; раз в месяц отдельный агент сверяет каждый кубик со всеми источниками фактов.
