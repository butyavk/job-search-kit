## Claude Code (или приложение Claude с плагинами)
```
/plugin marketplace add butyavk/job-search-kit
/plugin install job-search-kit@job-search-kit
```
Потом в пустой папке для поиска: `/start`.

## Папкой
Любой Claude с доступом к файлам: склонируйте набор как `kit/` рядом с будущим `me/`.
```
mkdir job-search && cd job-search
git clone https://github.com/butyavk/job-search-kit kit
echo '@kit/CLAUDE.md' >> CLAUDE.md
```
Однострочный `CLAUDE.md` заставляет Claude Code загружать правила набора в каждой сессии, начатой в `job-search/` (сам он `kit/CLAUDE.md` не читает). В другом клиенте начните с «сначала прочитай kit/CLAUDE.md». Потом скажите «начнём поиск работы».

## Проект claude.ai
Включите выполнение кода, загрузите архивы навыков, добавьте файлы проекта из последнего [релиза](https://github.com/butyavk/job-search-kit/releases/latest), а `CLAUDE.md` — в инструкцию проекта. По шагам: [Как это устроено → claude.ai](../how-it-works/#работа-в-claudeai-проект).

## Что подключить
Каждое подключение открывает свою часть пути; набор работает с тем, что есть у вашего Claude.

| Подключение | Что даёт |
| --- | --- |
| Почта (коннектор Gmail) | ответы, отказы и приглашения — в трекер; черновики фоллоу-апов в нужной ветке |
| Календарь (коннектор Google Calendar) | интервью на неделе; свободные слоты для ответа |
| Claude in Chrome | залогиненный LinkedIn (алерты, поиск, People, сообщения), сайты за логином и все формы заявок — заполняются в вашем браузере, без отправки |
| Встроенный браузер (приложение Claude) | площадки, которые не отдаются простым запросом (hiring.cafe, levels.fyi), гостевой API LinkedIn |
| [tracker-mcp](https://github.com/butyavk/tracker-mcp) | трекер, даты фоллоу-апов, воронка, выгрузка в календарь (нужен `uv`) |
| Запись звонков с расшифровкой (по желанию) | разбор в тот же день по расшифровке, если компания разрешает запись |
| Запланированные задачи | ежедневная проверка, еженедельный проход, ежемесячный разбор |

## Обновление
Плагин: `claude plugin marketplace update job-search-kit`, затем `claude plugin update job-search-kit@job-search-kit` и перезапуск (или `/plugin` в приложении → маркетплейс → обновить). Папка: `git pull` в `kit/`. Ваш пакет лежит отдельно, обновление его не трогает.
