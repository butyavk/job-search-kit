# Job search kit

[English version](README.md) · **Сайт:** [butyavk.github.io/job-search-kit/ru](https://butyavk.github.io/job-search-kit/ru/)

Весь поиск работы с Claude — от «хочу новую работу» до оффера. Claude находит и ранжирует вакансии, ищет людей, которым написать, собирает каждую подачу, ведёт трекер и фоллоу-апы, каждое утро разбирает почту, готовит к каждому этапу, проводит моки и разборы. **Claude готовит — отправляете вы.**

Набор вырос из настоящего двухмесячного поиска на роли engineering manager: около сотни подач, интервью до финалов и цифры за каждым правилом — гейт «глазами скринера», сроки фоллоу-апов, покрытие ключевых слов в CV.

## Путь — 9 команд

| Шаг | Команда | Что делает Claude | Что остаётся вам |
| --- | --- | --- | --- |
| 1. Старт | `/start` | Собирает ваш пакет из CV и нескольких сессий вопросов. Предлагает роли, уровни, страны, удалёнку или переезд, нижнюю границу денег по рынку. Подключает трекер и расписание. | выбрать из предложенного, подтвердить факты |
| 2. Поиск | `/find` | Читает LinkedIn, борды компаний через API ATS, площадки (hiring.cafe, Himalayas, HN «Who is hiring», levels.fyi…) и борды стран; проверяет каждую вакансию двумя путями, прогоняет гейт из пяти пунктов, ранжирует остальное. Короткий список — в трекер. | выбрать, куда подаваться |
| 3. Люди | `/people <компания>` | Находит нанимающего менеджера, рекрутёра, знакомых в компании, путь через реферала; пишет черновики записок. | отправить |
| 4. Подача | `/apply <вакансия>` | Гейт, CV под вакансию с таблицей ключевых слов, письмо, ответы формы; заполняет форму, не отправляя; планирует записку и фоллоу-апы. | нажать «отправить», сказать «подал» |
| 5. Каждый день | `/today` (и по расписанию) | Почта и LinkedIn → трекер, новые вакансии из алертов, фоллоу-апы с черновиками, интервью на неделе. | отправить черновики |
| 6. Этап | `/prep <компания> <этап>` | Формат и люди, вероятные вопросы с ответами из ваших кубиков, тренажёр под формат, план по дням и страница для заучивания: первые фразы и опоры историй. | учить вслух |
| 7. Мок | `/mock <вид>` | Ежедневный дрилл по странице с отметками или полный мок: рекрутёр, менеджер, поведенческое, system design, live coding — голосом или текстом, с честным разбором. | пройти дрилл и мок |
| 8. После звонка | `/debrief` | Что было и следующий шаг; новые факты — в пакет; напоминания. | рассказать, как прошло |
| 9. Раз в месяц | `/review` | Воронка, разбор отказов, что поменять в рамке, CV или источниках; проверка пакета и фактов. | согласиться с правками |

Всё остальное — словами: «собери ответ на B03», «добавь факт», «X отказали», «подал в Y».

**Что идёт само:** ежедневная проверка каждое утро (пуш — только когда есть что делать), еженедельный проход поиска, ежемесячный разбор — запланированными задачами, если они есть в вашем приложении Claude (`schedules/`). Даты фоллоу-апов трекер выгружает и в календарь.

## Ваши данные остаются вашими
Всё о вас лежит в отдельной папке — **пакете** `me/`: факты с источниками, кубики ответов, рецепты, чего не говорить, профиль и рамка поиска. Набор его только читает. В этот репозиторий пакет не попадает никогда (его закрывает `.gitignore`).

**Кубики ответов** — сердце пакета: маленькие проверенные фразы — вся история целиком, первая фраза, контекст, ваше действие, результат, вывод — на английском и на родном языке. Любой ответ на любой вопрос для любой компании — цепочка кубиков, поэтому факты на всех интервью одни и те же. Пример — `examples/example-story.md`.

## Самостоятельность
По умолчанию Claude спрашивает перед каждым действием наружу, а делаете его вы: подать, отправить, принять, забронировать. Если хотите, чтобы какой-то вид сообщений Claude отправлял сам — например, первый фоллоу-ап в ветке ATS по шаблону, — скажите правило; он запишет его в профиль с датой и вашими словами. Правило работает только в живой сессии, которую запускаете вы; запланированные задачи никогда ничего не отправляют. Пароли, аккаунты, деньги и офферы — всегда ваши.

## Установка

**Claude Code (или приложение Claude с плагинами):**
```
/plugin marketplace add butyavk/job-search-kit
/plugin install job-search-kit@job-search-kit
```
Потом в пустой папке для поиска: `/start`. Обновить потом: `claude plugin marketplace update job-search-kit`, затем `claude plugin update job-search-kit@job-search-kit` (в режиме папки — `git pull` в `kit/`). Пакет обновление не трогает.

**Папкой** (любой Claude с доступом к файлам): склонируйте набор как `kit/` рядом с будущим `me/`:
```
mkdir job-search && cd job-search
git clone https://github.com/butyavk/job-search-kit kit
```
Claude читает `kit/CLAUDE.md`. Скажите «начнём поиск работы».

**Проект claude.ai без shell:** загрузите навыки (`skills/*`, каждую папку архивом) в Настройках → Skills; `CLAUDE.md` — в инструкцию проекта; `bank/questions.md`, `pack-template/` и нужные шаблоны — в файлы проекта. Файлы пакета Claude выдаёт по одному, вы их загружаете. Команды — словами. Подробно: [docs/how-it-works.ru.md](docs/how-it-works.ru.md#claudeai).

**Трекер** — открытый MCP-сервер [tracker-mcp](https://github.com/butyavk/tracker-mcp); `/start` его подключает (`uvx tracker-mcp new …`, потом одна строка `claude mcp add` или файл `.mcpb` для приложения). Нужен `uv`.

## Что подключить
Набор работает с тем, что есть у вашего Claude; каждое подключение открывает свою часть пути.
| Подключение | Что даёт |
| --- | --- |
| Почта (коннектор Gmail) | ответы, отказы и приглашения — в трекер; черновики фоллоу-апов в нужной ветке |
| Календарь (коннектор Google Calendar) | интервью на неделе; свободные слоты для ответа |
| Claude in Chrome | залогиненный LinkedIn (алерты, поиск, People, сообщения), сайты за логином и все формы заявок — заполняются в вашем браузере, без отправки |
| Встроенный браузер (приложение Claude) | площадки, которые не отдаются простым запросом (hiring.cafe, levels.fyi), гостевой API LinkedIn |
| tracker-mcp | трекер, даты фоллоу-апов, воронка, выгрузка в календарь |
| Запись звонков с расшифровкой (по желанию) | разбор в тот же день по расшифровке, если компания разрешает запись |
| Запланированные задачи | ежедневная проверка, еженедельный проход, ежемесячный разбор |

Откуда берутся вакансии — LinkedIn, борды компаний в ATS, площадки, борды стран — и как читается каждая: [skills/job-search/sources.md](skills/job-search/sources.md).

bank/             универсальный банк вопросов: 134 вопроса, 26 в ядре, ролевые пакеты, 13 архетипов историй
pack-template/    пустой пакет — скопировать как me/
templates/        контекст подготовки, звонок с рекрутёром, разбор, разводка историй, карточка дизайна, референсы…

Внутренние файлы набора (навыки, команды, шаблоны) — на английском: их читает Claude. Говорит он с вами на вашем языке, а всё, что уходит работодателю, пишет на языке вакансии.

## Подготовка к интервью
Цикл на каждый этап: `/prep` → выучить страницу → каждый день `/mock drill` → полный мок за два дня → интервью → `/debrief` в тот же день. По шагам — [на сайте](https://butyavk.github.io/job-search-kit/ru/prep/).
