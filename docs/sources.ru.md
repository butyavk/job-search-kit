# Откуда берутся вакансии — источники и как их читать

Перевод `skills/job-search/sources.md` для людей; Claude работает по английскому файлу, при правке меняйте оба.

Статусы — из настоящего двухмесячного поиска (осень 2026). Сайты меняются: если источник перестал читаться, запишите это с датой в список источников рамки (`me/search-rules.md`), чтобы следующая сессия не потеряла на нём час.

**Три способа читать**, от дешёвого к дорогому:
- **API / fetch** — из сессии (WebFetch или `curl`, где сеть сессии позволяет). Быстро; годится для проходов по сотням бордов.
- **Встроенный браузер** — читает страницы, которые закрыты от fetch (Cloudflare, robots), и гостевой API LinkedIn.
- **Chrome кандидата (расширение)** — LinkedIn с логином, сайты за логином и все формы заявок.

Если `curl` из сессии получает 403/429, выполните тот же `fetch(url, {credentials: 'omit'})` из вкладки браузера. Делайте паузы между запросами (Workable — около 12 с; гостевой LinkedIn — 429 примерно после 40 быстрых запросов).

## 1. LinkedIn — самый широкий источник
- **Сохранённые алерты** (названия × регионы) — ежедневная проверка читает новые карточки за 24 часа.
- **Гостевой API без логина:** `linkedin.com/jobs-guest/jobs/api/seeMoreJobPostings/search?keywords=<title>&location=<…>&geoId=<id>&f_TPR=r86400` (10 карточек на страницу; `r432000` = 5 дней), полный текст — `…/jobs-guest/jobs/api/jobPosting/<id>`. Работает и во встроенном браузере.
- **Поиск с логином** (расширение): `linkedin.com/jobs/search/?keywords=<…>&geoId=<id>`. Локация по умолчанию берётся из прошлого поиска — всегда задавайте `geoId` (92000000 = весь мир).
- Ловушки:
  - у страны с названием как у штата США нужен её `geoId` (Грузия-страна = `106315325`; слово «Georgia» — это штат);
  - `f_WT=2` (remote) почти всегда значит удалёнку *внутри одной страны*, а не «откуда угодно» — читайте текст;
  - `f_C=` с неверным id компании молча отдаёт ленту рекомендаций;
  - число откликов в гостевом виде отстаёт от вида с логином (однажды «<25» против 79);
  - **id вакансии датирует публикацию:** id растут примерно на 0,4 млн в день, поэтому карточка «Reposted 2 days ago» со старым id — старая роль (±3–5 дней).
- Посты агентств со скрытым клиентом проверить нельзя: пропускайте.
- **Люди** (для `/people`): `linkedin.com/company/<slug>/people/?keywords=recruiter` (или название команды), прокрутить, прочитать карточки; «<Имя> works here» — знакомый первой степени.

## 2. Борды компаний через публичные API ATS — лучший источник по известным компаниям
| ATS | Борд | Одна вакансия / форма |
| --- | --- | --- |
| Ashby | `api.ashbyhq.com/posting-api/job-board/<slug>?includeCompensation=true` | GraphQL с любой страницы `jobs.ashbyhq.com`: `POST /api/non-user-graphql?op=ApiJobPosting` (`jobPosting: null` = снята или скрыта; там же поля формы); `op=ApiJobBoardWithTeams` даёт `secondaryLocations` |
| Greenhouse | `boards-api.greenhouse.io/v1/boards/<slug>/jobs` (и `job-boards.eu.greenhouse.io`) | `…/jobs/<id>?questions=true` — выпадающие списки стран, вопросы о спонсорстве |
| Lever | `api.lever.co/v0/postings/<slug>` (ЕС: `api.eu.lever.co`) | то же с id вакансии |
| Workable | `apply.workable.com/api/v1/widget/accounts/<slug>?details=true` | `apply.workable.com/api/v2/accounts/<slug>/jobs/<code>` |
| Teamtailor | `<slug>.teamtailor.com/jobs.json` | страница (может показывать город HQ там, где написано «Fully Remote») |
| Pinpoint | `<slug>.pinpointhq.com/postings.json` | пустое тело → полный текст часто в копии на LinkedIn |
| BambooHR | `<slug>.bamboohr.com/careers/list` | |
| Breezy | `<slug>.breezy.hr/json` | |
| SmartRecruiters, Recruitee, join.com, Personio, Comeet | страница карьеры в браузере | формы Comeet живут в iframe |

- Slug часто есть в HTML страницы карьеры (`jobs.ashbyhq.com/<slug>/embed`) и не всегда совпадает с названием компании (`primer` — сеть школ в США, платёжная компания — `primer.io`; у компании может быть пустой и рабочий аккаунт Workable). Найденные slug храните в списке источников рамки.
- Борд, которого нет в выдаче поисковика, всё равно существует: около двух третей проиндексированных ссылок на ATS были устаревшими, а скрытые вакансии Ashby открываются только по прямой ссылке.
- Борды без API (большие компании, свои сайты): браузер; читайте все страницы — поиск сайта может не фильтровать.

## 4. Борды стран (каналы кандидата)
Добавьте борды каждой страны из рамки. Как найти их для новой страны: поиск «<страна> job board <роль>» и «<страна> tech jobs»; проверьте, что у вакансий есть даты и это не перепосты с LinkedIn, оставьте 2–3 борда со своими вакансиями и впишите их в `me/search-rules.md`. Примеры, которые сработали (для рынков автора набора; у других стран свои):
- **Сербия:** helloworld.rs, infostud — в списках стоит **дедлайн** подачи, а не дата публикации: дату берите из самой вакансии и сверяйте с LinkedIn, оставляйте более раннюю.
- **Грузия:** jobs.ge.
- **Русскоязычный рынок:** getmatch (браузер; фильтры только настоящими кликами; `vacancies/remote/lead?pa=7d&se=lead&sp=remote`), careerspace, Telegram-каналы (только браузер; превью через fetch без дат).
- **Спонсорство в UK:** реестр лицензированных спонсоров на gov.uk (большой CSV; из сессии может не открываться — тогда проверяйте спонсорство в вакансии и на странице карьеры).

## 5. Не стоит времени (на осень 2026, для удалённых ролей руководителя из Сербии и Грузии — для другого рынка проверьте заново)
Remotive, Jobgether, Adzuna, jooble, Indeed, Glassdoor и Google Jobs (шум), поиск Built In, TrueUp (логин), EU Remote Jobs (мёртв), cord.co, Honeypot, Remote Europe, geekjob, joberty (без JS), страницы компаний на LinkedIn через fetch (robots). Новые сайты в основном повторяют вакансии ATS, уже прочитанные через API.

## 6. Ритм, который сработал
- Каждый день: алерты LinkedIn (24 часа) — в `/today`.
- Каждую неделю: борды всех компаний из трекера и из целевого списка рамки (API ATS, только роли, опубликованные или обновлённые за окно) + площадки и борды стран выше — `schedules/weekly.md`.
- После нескольких полных проходов перестаньте добавлять новые сайты: следите за известными бордами и свежими вакансиями.
