Scope: $ARGUMENTS (empty = everything new since the last pass, or the last 7 days).

Follow the `job-search` skill: read `me/search-rules.md` and the tracker first (skill `tracker`: no duplicates, one application per company in 3–4 weeks), then sources → two-source check → gate → ranking. A single link in the arguments means: check and gate just that vacancy.

Output: a dated search-pass file (`me/search/<date>-pass.md`, or a project document) and a short list of at most 8 rows — company, role, format and location, date and applicants, score, why it fits, the main risk or zero in the gate, the route through a person if there is one. Offer to add the short list to the tracker (dry run first) and to run `/apply` or `/people` for the top rows. Do not apply, connect or message anyone.
