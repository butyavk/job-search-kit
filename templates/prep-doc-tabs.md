# The prep document: tabs and what fills them

One document, a tab per topic.

| Tab | What is inside | Source |
| --- | --- | --- |
| Recruiter | what to find out and what to say (`recruiter-call.md`) | `me/profile.yaml` (money, contract, notice), `me/never-say.md`, the posting |
| Company and role | the product in plain words; how it earns; scale; role and team; risks of the area; a 90-day plan; questions for the hiring manager | the posting, site, blog, emails; an unknown company — only the posting, the rest as questions |
| Cheat sheet | 25–30 answers with anchors and block IDs: intro, why the company, why the role, key stories, awkward places in the CV | `me/recipes.md`, `me/blocks/`, `me/never-say.md` |
| Interview language (usually English) | the domain glossary, short answers (strengths, weakness, tech debt, AI), think-aloud phrases | blocks, `english-register` |
| Behavioral / manager | likely questions → answer; minute answers (`answer-card.md`); the story split (`story-split.md`); questions for the interviewer | recipes and blocks, bank section Z |
| Values | each value → first line → story → «if they ask»; values unknown — the usual set and a question for the recruiter | the values page |
| System design | the 6-step frame; cards for likely tasks (`sd-task-card.md`); typical blocks (`skills/system-design/patterns.md`); numbers for estimates | the company's product, reviews, interviewers' code; bridges from blocks |
| One-page plan | the 6 steps on one sheet, 2–3 hints per step — rewrite by hand | the System design tab |
| Metrics | what → how we count → target → source → what we do; own numbers and how to explain them | `me/facts.md` (definitions) |
| Learn | the map (question → first sentence → story), story anchors in four steps, the drill plan by days and the marks table (`learning-sheet.md`); rewritten by hand the day before | the cheat sheet, recipes and blocks |
| Final and references | 3 main questions for the founder or CTO and spares; short answers; references, messages, memo (`references.md`) | leaders' blog and posts; the pack |
