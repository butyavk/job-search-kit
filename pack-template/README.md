# me — the candidate pack (template)

Copy this folder as `me/` next to the kit (`kit/`) and never publish it: it will hold your facts, answers, money and contacts. You do not fill it in by hand — run `/start`, and Claude drafts it from your CV and then asks you questions.

| File | What it is |
| --- | --- |
| `profile.yaml` | contacts, status, work authorization, form answers, money, languages, paths, autonomy rules |
| `facts.md` | facts with definition, source and confirmation date: roles, teams, numbers, who did what |
| `blocks/` | answer blocks (English plus your native language, English only if it is your native one) — format in the `answer-blocks` skill |
| `recipes.md` | bank question → first line and chains of blocks; your story set |
| `never-say.md` | what not to say and why; people not to contact; filler words |
| `voice.md` | pronunciation and speech errors from mocks and calls |
| `search-rules.md` | the search frame: roles, geography, money, gate, sources, message rules, timing |
| `questions-extra.md` | questions met in interviews that are not in the kit's bank |
| `schedules/` | the values the scheduled runs are filled with, and the read-only tracker entry they load |
| `runs/` | what scheduled runs wrote: one summary per run |

An example story cut into blocks: `examples/example-story.md` in the kit.
