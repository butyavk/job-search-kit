# Recipes: question → blocks

For every question in the bank (`bank/questions.md` in the kit): a first line and chains of blocks. `—` means no recipe yet: build it with Claude («compose an answer to B03»). Core ★ first, then behavioral B, then the ◆ questions of your track.

Columns: «First line» — the ID of an `O` (or `S`) block; «Short» and «Long» — chains of IDs in backticks, for example `CHK-S1` and `CHK-O1 → CHK-A1 → CHK-R1 → CHK-L1`. «Notes» is free text: IDs there do not count as a recipe, so write the nearest story without backticks.
